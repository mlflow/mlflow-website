MLflow 3.16.1 is a patch release that includes bug fixes and documentation updates.

Breaking changes:

- [Docs / Tracking] Remove the default basic-auth admin password shipped in `basic_auth.ini` (GHSA-gq3w-7jj3-x7gr) ([#25751](https://github.com/mlflow/mlflow/pull/25751), [@tanghaoji](https://github.com/tanghaoji))

Features:

- [Evaluation] Add a `timeout` option to the `scorer` decorator ([#25720](https://github.com/mlflow/mlflow/pull/25720), [@smoorjani](https://github.com/smoorjani))
- [Evaluation] Propagate scorer version to assessment metadata ([#25570](https://github.com/mlflow/mlflow/pull/25570), [@B-Step62](https://github.com/B-Step62))
- [Tracing] Support span links for Unity Catalog traces ([#25597](https://github.com/mlflow/mlflow/pull/25597), [@B-Step62](https://github.com/B-Step62))

Bug fixes:

- [Model Registry] Fix S3 multipart upload encryption arguments ([#25772](https://github.com/mlflow/mlflow/pull/25772), [@james-fletcher-db](https://github.com/james-fletcher-db))
- [Tracking / UI] basic-auth: serve the web UI to non-admins under fail-closed authorization ([#25672](https://github.com/mlflow/mlflow/pull/25672), [@mkBGD](https://github.com/mkBGD))

For a comprehensive list of changes, see the
[release change log](https://github.com/mlflow/mlflow/releases/tag/v3.16.1),
and check out the latest documentation on [mlflow.org](http://mlflow.org/).
