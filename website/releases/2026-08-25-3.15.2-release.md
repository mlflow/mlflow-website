MLflow 3.15.2 is a patch release that includes several major features and improvements.

Features:

- [Evaluation] Support immutable evaluation dataset versions ([#24845](https://github.com/mlflow/mlflow/pull/24845), [@danielseong1](https://github.com/danielseong1))
- [Evaluation] Add `scorer_ensemble` primitive for combining scorer results ([#24749](https://github.com/mlflow/mlflow/pull/24749), [@alkispoly-db](https://github.com/alkispoly-db))

Bug fixes:

- [Evaluation] Preserve base judge invocation flow in MemAlign aligned judges ([#24883](https://github.com/mlflow/mlflow/pull/24883), [@veronicalyu320](https://github.com/veronicalyu320))
- [Tracking] Pre-import `databricks.sdk` in Databricks to avoid telemetry deadlock ([#24841](https://github.com/mlflow/mlflow/pull/24841), [@aaronteo-db](https://github.com/aaronteo-db))
- [Build / Tracking] Align `runs.status` constraint metadata ([#24890](https://github.com/mlflow/mlflow/pull/24890), [@joshuawong-db](https://github.com/joshuawong-db))

For a comprehensive list of changes, see the [release change log](https://github.com/mlflow/mlflow/releases/tag/v3.15.2), and check out the latest documentation on [mlflow.org](http://mlflow.org/).
