MLflow 3.16.0 is a big release for GenAI observability and prompt engineering. It ships a fully **redesigned trace explorer** as the default traces experience, **agentic custom trace views** you can build by describing what you want, an enhanced **Prompt Playground** wired into the Prompt Registry, and first-class **span links** for connecting related spans across traces. Here's what's new.

## 1. **A Redesigned Trace Experience**

<img
  src="/img/releases/3.16.0/traces-v4-overview.png"
  width="100%"
  style={{ display: "block", marginBottom: 24 }}
/>

The trace explorer has been rebuilt from the ground up and is now the **default** traces experience. The new Traces table brings tighter row density, a cleaner header, and smoother navigation, along with a redesigned span-tree explorer (v2) ported to OSS. You can **reorder columns** to put what matters first and add **configurable custom columns** backed by any trace tag or metadata field — so the fields you care about are always one glance away.

Sessions are now folded directly into the traces view via **session grouping**, replacing the standalone Sessions tab, so multi-turn conversations live right alongside the rest of your traces.

## 2. **Agentic Custom Trace Views**

<img
  src="/img/releases/3.16.0/custom-trace-view.png"
  width="100%"
  style={{ display: "block", marginBottom: 24 }}
/>

Every team inspects traces differently — so instead of a fixed layout, 3.16.0 lets you **build your own trace views by describing them to the MLflow Assistant**. Submit a prompt describing the view you want and the Assistant assembles it for you; save it, rename it, and it persists per experiment via experiment tags. You can create multiple views, delete the ones you no longer need, and work within a per-experiment saved-view limit. Local Assistant providers with structured responses are supported, so the feature works across a range of setups.

## 3. **Prompt Playground Enhancement**

<img
  src="/img/releases/3.16.0/prompt-playground.png"
  width="100%"
  style={{ display: "block", marginBottom: 24 }}
/>

MLflow 3.16.0 introduces an interactive **Prompt Playground** as a first-class experiment tab. Compose system and user turns, tune model parameters, define input variables, attach tools, and set a structured response format — then run the conversation right in the UI.

The Playground is wired directly into the **Prompt Registry**: load any registered prompt version straight into the editor, iterate on it, and save your changes back as a new version — model configuration and prompt type included. It closes the loop between experimenting with a prompt and versioning the one you want to keep.

## 4. **Span Links**

<img
  src="/img/releases/3.16.0/span-links.png"
  width="100%"
  style={{ display: "block", marginBottom: 24 }}
/>

Spans rarely stand alone — a retrieval step, a tool call, or a downstream trace is often related to the span you're looking at. MLflow 3.16.0 adds first-class **span links** so those relationships are captured and navigable. The **TypeScript SDK** gains full `SpanLink` support for recording links between spans, and the trace explorer now **normalizes span links from OTLP endpoints** and surfaces them in a dedicated Links tab — click through to jump straight to the destination span.
